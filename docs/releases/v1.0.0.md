# DHCP 改静态 IPv4 v1.0.0

首个公开版本：把 Windows 网卡的 IPv4 从 DHCP 自动获取改成固定 IP，**掩码 / 网关 / DNS 全部沿用当前网络设置**，并可一键恢复 DHCP。

![界面预览](https://github.com/zkkk9555/dhcp-to-static-ipv4/raw/main/docs/preview.png)

## 亮点

- 单文件 EXE，37~48 KB，不联网、不上传数据；
- 依赖系统自带 .NET Framework 4.8（Windows 10/11 无需安装任何东西）；
- 打开即显示当前网卡、IP、掩码、网关、DNS、DHCP 服务器；
- 改成固定 IP 只改地址，其他信息自动复用；
- 一键恢复 DHCP：执行 netsh source=dhcp + ipconfig /renew，并等待新租约；
- 安全校验：IP 格式、同网段、网关/广播地址、目标地址是否已被占用（ping 探测）；
- 支持高 DPI 缩放，界面按 8pt 间距系统与卡片式布局设计。

## 使用要求

- Windows 10 / Windows 11
- 管理员权限（程序清单声明 requireAdministrator，启动会弹 UAC）

## 使用

1. 下载并运行 DHCP-Static-IPv4.exe（UAC 点「是」）；
2. 选择网卡（通常为 WLAN 或以太网）；
3. 在「目标 IP 地址」中填写想要的固定地址（默认已填当前 IP），点击「应用为固定 IP」；
4. 需要还原时点击「恢复为 DHCP」。

> 目标 IP 必须与默认网关同网段，建议放在路由器 DHCP 地址池之外。例如 DHCP 池 192.168.0.100 - 192.168.0.240，本机固定用 192.168.0.241。

## 命令行（可选，需管理员）

~~~text
DHCP-Static-IPv4.exe --info  --log info.txt
DHCP-Static-IPv4.exe --set 192.168.0.241 --log set.txt
DHCP-Static-IPv4.exe --dhcp  --log dhcp.txt
~~~

## 已知边界

- 只修改 IPv4 与 IPv4 DNS，不改 IPv6；
- 恢复 DHCP 后地址可能变化，依赖该 IP 的服务需要同步更新；
- 修改瞬间会短暂断网（通常 1~3 秒）。
